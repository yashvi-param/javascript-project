# ShopEase - JavaScript Shopping Cart

A larger frontend e-commerce/cart project built with HTML, CSS and Vanilla JavaScript.

## Features
- 20 products with real product photography loaded from Unsplash
- Product search
- Category labels
- Product ratings
- Add to cart
- Increase/decrease quantity
- Remove products
- Clear cart
- Automatic total calculation
- localStorage persistence
- Responsive product grid
- Demo checkout
- Lazy-loaded product images

## Technologies
HTML5, CSS3, JavaScript ES6+, DOM Manipulation, Events, Array Methods, localStorage.

## How to run
Open `index.html` in a browser, or use VS Code Live Server.

Note: Product photos are loaded from Unsplash, so an internet connection is needed to display them.
